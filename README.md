# 2026 高教社杯 C 题建模项目归档 — 微网与外部电网电力调控策略

本目录是 **2026 年高教社杯全国大学生数学建模竞赛 C 题**（微网与外部电网电力调控策略）的求解代码与结果归档。内容按「问题」组织：求解脚本集中在 `03_代码/`，模型产物与数据校验集中在 `04_结果/`。

> 说明：本归档为从原始工程（含 `00_题目与原始数据/`、`05_图件/` 等）中抽取的**最小支撑子集**，仅保留「最终产出 + 对应求解/出图脚本」。原始数据附件、重复图件、完整运行环境未一并复制，部分脚本中的相对路径仍以原工程目录结构为准。

## 3. `03_代码/` — 求解与绘图脚本

> 通用约定：时间窗口以 **10 分钟（144 段/日）** 为最小粒度；功率单位 kW、电量单位 kWh、电价单位 元/(kWh)、时段长 Δt = 1/6 h；充电效率 η = 0.9；储能运行区间 [1200, 10800] kWh；单段充放电功率上限 5000 kW。

### 3.1 `问题1/` — 问题一：单日 MILP 优化

| 文件            | 作用                                                                                                                                 |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `口径.py`       | **参数/常量模块**（被其它脚本 import）。定义时段口径、单位、储能边界 `E_MIN/E_OP`、效率 `ETA`、功率上限 `P_MAX`、事件起始储电量等。                                              |
| `模型.py`       | **模型层**：单日 MILP（确认执行层）。13 个时段变量（a/e/C/D/E/w/r/u/np/nm/y/z/b）+ 窗口初值 `E0`；约束含执行一致、完整平衡、储能不能越界、功率界、互弃、净额正负互析；目标含 plan/point/adj 三类成本。 |
| `检查.py`       | **校验器**：硬约束残差、量纲一致性、检查点与费用复算，输出 PASS/FAIL 自检结论。                                                                                    |
| `绘图_数据预处理.py` | 数据预处理可视化：按 9 个预处理环节组织 7~8 张图（时间对齐、质量校验、异常辨识、极端值保护、变量分布、特征构造、相关性分组）。                                                                |
| `绘图_问题1求解.py` | 问题一求解可视化：用项目自带模型重解、与 `result1.xlsx` 逐项对照，输出 PNG(300dpi)+SVG 与运行日志。                                                                 |
| `写模板.py`      | **F1 正式模板填盘**：按官方 5 个模板（result1/result2/result3/result4-2/result4-3）填全年结果，处理时钟口径（6 段真实时钟区间）与修正。                                    |

### 3.2 `问题2-3/` — 问题二 / 问题三：多日滚动优化、两阶段随机线性规划、MPC

| 文件                 | 作用                                                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `p10_core.py`      | **核心库**：数据读取、滑动预测、整日偏差场景、两阶段随机 LP/MILP 内核（本模型采用LP）、实时调度、核算。所有模型为 LP（HiGHS / `scipy.optimize.linprog`）。路径默认由文件位置推导，可用环境变量 `MICROGRID_ROOT / MICROGRID_RES / MICROGRID_LOG` 覆盖。 |
| `p15_forecasts.py` | 逐日历史选型：模型与偏差仅使用当日之前的信息（因果预测）。                                                                                                                                                 |
| `p95_q23_v4.py`    | **Q2/Q3 固定电价因果重跑驱动**：protocol `q23_janwarm_v4`，自 2025-01-01 00:00 起 E=6000 kWh，保留 1 月作可见预热，仅写出到指定 case 目录。                                                                    |
| `p95c_finish.py`   | **v4 单案例合成器**：读取 `paths/*.pkl`，执行部署策略并写出全部主要产物（承接 `p95 run_main` 的末尾合成阶段）。                                                                                                    |

### 3.3 `问题4/` — 问题四：口径 B（00:00 未知当日电价）

> 口径区别（改题 §5.A）：**决策用预测价 `price_dec`，结算用真实价 `price_settle`**；跨日储备价值 `v` 用「逐日滑动」(N1 规则) 的因果价格预测构造。

| 文件                     | 作用                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| `p10_core.py`          | 问题四核心库（同 q23 内核，适配口径 B 的价格/结算口径）。                                                                  |
| `p102_q4_core.py`      | **口径 B 核心模块**：日前计划 LP、10 分钟执行器；账单/调增费改用真实结算价重算；跨日储备价值用因果预测。                                        |
| `p102c_q4_finish.py`   | **口径 B 单案例合成器**：读 `paths/*.pkl`，部署策略并写出产物（支持 track/refresh-mode/v-mode/price-source 等开关）。          |
| `p105_q4_specified.py` | **四个指定日期的表1/表2/表3 生成器**（Q4-2 B 与 Q4-3 复用）：输出 `四个指定日期_表123_q4B.json/.md`，并把 q42 行合并进 `指定日期表格.json`。 |
| `p106_pi_q4.py`        | 按「被比较路径 vs 真实 2/1 初始」计算全期 PI（价格完全已知）上界与下界，量化「信息价值 + 算法/滑动近似」误差。                                    |
| `p107_q4_stats.py`     | **配对统计**（7 日块 bootstrap）：补齐此前只报总额的下界，覆盖组内/跨组/价格源/刷新等多组对照。                                          |
| `p108_q4_vstep_d4.py`  | **补充可复现脚本**：根据保留的 pkl 路径重算并覆盖 `v台阶_Q4B.json` / `d4_Q4B.json`，用于核验既有数值与后续复现。                        |
| `p41c_figures_q4.py`   | 问题四口径 B 图件（重绘受影响的 `result_q4_costs`，新增四格分解与价格预测质量图）。                                               |

## 5. 运行与复现说明

- **路径约定**：多数脚本默认以「脚本所在目录的上一级 = 工程根」推导 `00_题目与原始数据/`、`04_结果与校验/` 等路径；脚本内可能仍残留少量旧机器绝对路径（如 `C:\Users\John\...`），运行前需按本机目录调整或设置环境变量。
- **环境变量（问题2-3 / 问题4 内核）**：可用 `MICROGRID_ROOT`、`MICROGRID_RES`、`MICROGRID_LOG` 覆盖默认根/结果/日志目录，便于把流水线重跑到临时目录而不覆盖既有 `results/` 与校验日志。
- **口径 A / 口径 B**：
  - 问题一、问题二、问题三使用**口径 A**（决策与结算电价一致）；
  - 问题四使用**口径 B**（00:00 未知当日电价，决策用预测价、结算用真实价）。详见 `03_代码/问题4/问题4_已切换为口径B.md`。
- **Python 依赖**：`numpy`、`pandas`、`scipy`（HiGHS `linprog`/`milp`）、`openpyxl`、`matplotlib`，建议 Python 3.11+；部分脚本依赖 `utils/` 下的 `setup_style / export_figure / visual_qa`（原工程，本归档未含）。

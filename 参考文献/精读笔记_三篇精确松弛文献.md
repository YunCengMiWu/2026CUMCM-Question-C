# 三篇「精确松弛」文献精读笔记

> 用途：为"储能充放电互补约束可以去掉 0-1 变量、直接用 LP/凸松弛求解"提供文献依据。
> 配套：本工作区问题2–4 的模型为连续两阶段随机 LP，互斥性由 τ 吞吐罚项 + 保 SOC 配对消去 + 逐槽核验保证。
> 原文（PDF）位于本目录，文本提取件在 `_txt/`（P1/P2/P3.txt），逐篇摘要见 `_txt/P2_精读摘要.md`、`_txt/P3_摘要.md`。

## 0. 一句话结论

三篇回答的是同一个问题：**去掉"不能同时充放"的互补约束后，松弛问题的最优解在什么条件下仍自动满足 \(c_t d_t = 0\)？**
答案是：由**边际循环成本** \(\kappa^0_t = C^{CH}_t + \eta C^{DC}_t\) 与**可循环空间** \(\bar z_t\) 共同决定；且**在目标函数里加充放电损耗罚项可保证条件成立**。这正是本工作区 \(\tau(c+d)\) 罚项与"同 SOC 配对消去"的文献依据。

## 1. [A] 充要条件 + 两阶段恢复算法

**Shan Liu, Zhigang Li, Ye Guo, "A Necessary and Sufficient Condition for Exact Relaxation of Energy Storage Power Dispatch", arXiv:2607.21902v1 (2026-07-24), IEEE letter 体例。**

### 1.1 模型
单储能、\(T\) 个时段：
```
min  Σ_t ( C^CH_t p^ch_t + C^DC_t p^dc_t )
s.t. e_t = e_{t-1} + η^ch p^ch_t Δt − p^dc_t Δt / η^dc
     0 ≤ p^ch_t ≤ u_t P^max_ch ,  0 ≤ p^dc_t ≤ (1−u_t) P^max_dc ,  u_t ∈ {0,1}
     e ≤ e_t ≤ ē ,  e_T = e_0
```
**松弛**：\(u_t\in\{0,1\}\to 0\le u_t\le 1\)，等价于
$$p^{ch}_t\ge0,\quad p^{dc}_t\ge0,\quad p^{ch}_t+\alpha p^{dc}_t\le P^{max}_{ch},\qquad \alpha:=P^{max}_{ch}/P^{max}_{dc}$$
记松弛最优值 \(Q^R\)、原 MIP 最优值 \(Q\)，则 \(Q^R\le Q\)；**"最优值精确（optimal-value exact）"的定义就是 \(Q^R=Q\)**。

### 1.2 核心分解（Lemma 1，零 SOC 循环分解）
记 \(\eta:=\eta^{ch}\eta^{dc}\)、\(\Delta e_t:=e_t-e_{t-1}\)，互补动作为
$$p^{ch,0}_t=\frac{[\Delta e_t]^+}{\eta^{ch}\Delta t},\qquad p^{dc,0}_t=\frac{\eta^{dc}[-\Delta e_t]^+}{\Delta t}$$
任何实现同一 SOC 转移的松弛解都可**唯一**写成
$$p^{ch}_t=p^{ch,0}_t+z_t,\qquad p^{dc}_t=p^{dc,0}_t+\eta z_t,\qquad 0\le z_t\le \bar z_t(\Delta e_t)=\frac{P^{max}_{ch}-p^{ch,0}_t-\alpha p^{dc,0}_t}{1+\alpha\eta}$$
即：**同时充放 = 互补动作 + 一段不改变 SOC 的空转 \(z_t\)**；\(\bar z_t=0\) 当且仅当该转移已用满充/放功率上限。

### 1.3 关键量：边际循环成本
$$C^{CH}_tp^{ch}_t+C^{DC}_tp^{dc}_t=\underbrace{c_t(\Delta e_t)}_{互补成本}+\underbrace{\kappa^0_t z_t}_{循环代价},\qquad \boxed{\kappa^0_t=C^{CH}_t+\eta C^{DC}_t}$$
单时段松弛代价 \(c^R_t(\Delta e_t)=c_t(\Delta e_t)-[-\kappa^0_t]^+\bar z_t(\Delta e_t)\)，故
$$c^R_t=c_t\iff \kappa^0_t\ge0\ \text{ 或 }\ \bar z_t(\Delta e_t)=0$$

### 1.4 主定理
**Theorem 1（充要条件）**：\(Q^R=Q\) **当且仅当**松弛问题存在最优 SOC 轨迹 \(e^\*=(e^\*_0,\dots,e^\*_T)\) 使
$$[-\kappa^0_t]^+\,\bar z_t(e^\*_t-e^\*_{t-1})=0,\qquad \forall t$$
（原文结论句：*"the stagewise gap is \([-\kappa^0_t]^+\bar z_t\), so SCD creates a true gap only when it is both profitable and physically feasible."*）

### 1.5 表 I：五种情形（"什么时候同时充放无害"）
| \(\kappa^0_t\) | \(\bar z_t\) | 松弛最优 \(z^\*_t\) | 可能出现 SCD | 该转移上是否精确 |
|---|---|---|---|---|
| \(>0\) | 任意 | \(z^\*_t=0\) | 否 | **是** |
| \(=0\) | \(>0\) | 任意 \(z^\*\in[0,\bar z]\) | 是 | **是（仅退化表示）** |
| \(=0\) | \(=0\) | \(z^\*_t=0\) | 否 | 是 |
| \(<0\) | \(=0\) | \(z^\*_t=0\) | 否 | 是 |
| \(<0\) | \(>0\) | \(z^\*_t=\bar z>0\) | 是 | **否（真实间隙）** |

### 1.6 Algorithm 1（两阶段"松弛—恢复"）
1. 算 \(\eta\)、\(\kappa^0_t=C^{CH}_t+\eta C^{DC}_t\)；2. \(T^-=\{t:\kappa^0_t<0\}\)，\(T^0=\{t:\kappa^0_t=0\}\)；3. 解**完全松弛** LP；4. 算 \(z_t=\min\{p^{ch}_t,\ p^{dc}_t/\eta\}\)，\(V=\{t\in T^-:z_t>0\}\)；5. 若 \(V\ne\varnothing\)：**只在 \(T^-\) 上加 0-1** 重解（部分 MIP）；6. 对 \(T^0\) 中 \(z_t>0\) 的时段按互补动作恢复（即令 \(z_t=0\)）。

**算例（Gurobi）**：\(C^{CH}=[10,10,2.5,1,2.7075]\)、\(C^{DC}=[-5,-5,-5,5,-3]\) ⇒ \(\kappa^0=[5.4875,5.4875,\mathbf{-2.0125},5.5125,\mathbf{0}]\)。完全松弛 LP 在 \(t=3,5\) 出现 SCD，目标 \(-35.5919\)；只对 \(t=3\) 加 0-1 的部分 MIP 得 \(-30.4900\)，与全 MIP 相同；\(t=5\)（\(\kappa^0=0\)）按恢复步骤消去，**目标不变**。

## 2. [B] GRC 条件 + 罚参数准则（Applied Energy）

**Q. Wang et al., "An exact relaxation method for complementarity constraints of energy storages in power grid optimization problems", Applied Energy 371 (2024) 123592, DOI 10.1016/j.apenergy.2024.123592。**

- 模型：多时段**确定性**（24 h、\(\Delta t=1\) h）电网优化（ED/OPF），含节点平衡与支路潮流（(4)(5) 为**等式**，**无网损项**）；ESS 约束 (6)–(16)（含视在容量圆、备用、SOC 动态、首末 SOC 一致、增强线性约束 \(p^{ch}/\bar P^{ch}+p^{dc}/\bar P^{dc}\le1\)）。
- 互补/0-1 写法：\(p^{ch}\circ p^{dc}=0\)（式 (17)）；0-1 形式 (18)：\(0\le p^{ch}\le z^{ch}\bar P^{ch}\)、\(0\le p^{dc}\le z^{dc}\bar P^{dc}\)、\(z^{ch}+z^{dc}\le1\)、\(z\in\{0,1\}\)——**与本工作区写法一致**。
- **Condition C1（式 (19)(20)）**：
$$\lambda^p_{j,t}>\lambda^{p,C1}_{j,t}=\frac{\dfrac{1}{\eta^{dc}}\dfrac{\partial obj}{\partial p^{ch}}+\eta^{ch}\dfrac{\partial obj}{\partial p^{dc}}}{\eta^{ch}-\dfrac{1}{\eta^{dc}}}$$
物理含义：LMP 须高于由充放边际费用与效率构成的"下界"。
- **Theorem 1**：*"as long as the Condition C1 is satisfied, the relaxation is guaranteed to be exact, that is, SCD automatically holds."*（**充分**条件；证明见 Appendix A：KKT 相加得 \(\lambda^{ch,1}+\lambda^{dc,1}>0\)，与互补松弛矛盾）
- **Lemma 1**：C1 的精确松弛区域**包含** [20]（=[21] group A）、[21] group B/C、[22][23][24] 的条件区域，即最宽。
- **§4 强制精确松弛（本工作区 τ 罚项的文献依据）**：加充放电损耗罚项
$$C^{Pen}_{ESS}=\sigma_{ESS}\sum_{t}\sum_{n}\Bigl[\,p^{dc}\Bigl(\tfrac{1}{\eta^{dc}}-1\Bigr)+p^{ch}\bigl(1-\eta^{ch}\bigr)\Bigr]\tag{24}$$
Remark 7：*"a penalty is triggered as long as either \(p^{dc}\) or \(p^{ch}\) is non-zero."* 并给出**闭式判据** (30)（\(\sigma\) 需大于某正常数）、用 LMP 区间下界（±5×MAPE）替代预测值的流程 S1–S3，以及**两阶段 σ 调整方案**。
- 算例：IEEE 69/118/300，24 h，\(\eta\in[0.9,0.93]\)，\(\sigma=3\)，IPOPT/BONMIN。**目标值与 MIP 完全相同**（3807.4 / \(2.839\times10^6\) / \(3.641\times10^7\) 美元），耗时 12.35/68.85/85.62 s vs MIP 64.93/509.48/916.13 s；负 LMP 场景（最低 −10.67～−118.8 \$/MWh）下既有条件全 no、C1 全 yes 且精确。

## 3. [C] 多时段 OPF 的两条广义充分条件（补充材料）

**Qi Wang, Wenchuan Wu, Chenhui Lin, Shuwei Xu, Xueliang Li, "Sufficient Conditions for the Exact Relaxation of Complementarity Constraints for Storages in Multi-period OPF Problems"（补充材料）。**

- 模型：多时段**确定性 ACOPF**（24 h），极坐标 AC 潮流（**含网损**、变比/移相、线路容量、电压），节点平衡乘子 \(\lambda^p_{j,t}\)、ESS 含备用耦合与终端 SOC 一致；**松弛式 (25)** \(\;p^{ch}/\bar P^{ch}+p^{dc}/\bar P^{dc}\le1\)（乘子 \(\lambda^{relax}\)）替代互补约束。
- **Theorem 1：两条广义充分条件（任一成立即精确）**
  - **C1（(37)+(39)）**：\(\lambda^p_{j,t}>\lambda^{p,C1}_{j,t}\)，阈值含 \(\lambda^{ch,2},\lambda^{dc,2},\lambda^{S},\lambda^{RD,1},\lambda^{RU,1},\lambda^{relax}\)，为**后验**条件；
  - **C2（(38)+(40)）**：\(\lambda^p_{j,t}>\dfrac{\partial obj/\partial p^{ch}/\eta^{dc}+\eta^{ch}\partial obj/\partial p^{dc}}{1/\eta^{dc}-\eta^{ch}}-\{\cdots\}\)，线性成本时右端为**常数**，可用 LMP 预测**事前**检验（Remark 1）。
- **Lemma 1**：\(\lambda^{p,C2}\ge\lambda^{p,C1}\) ⟺ C1 的区域 ⊇ C2 的区域。**Lemma 2**：两条条件的 LMP 区域**都包含** [20]–[24] 六类既有条件。**Lemma 3**：**提供备用服务可扩大**松弛条件的适用范围。
- 负电价：§IV-B 与表 IV 中既有六类条件全 no、C1/C2 全 yes 且松弛模型精确。
- **强制精确**：*"Theoretically, as long as the penalty coefficient \(\sigma_{ESS}\) is large enough, Condition C2 is guaranteed to be met, ensuring the exactness of the relaxation."*
- 算例：IEEE 69 节点，24 h，35 个 ESS，\(\eta\in[0.9,0.93]\)，\(\sigma_{ESS}=3\)，IPOPT+BONMIN；**表 II 六个场景下 relaxed 与 MIP 目标值完全相同**（3776.8 / 3790.4 / 3807.4 / 3941.6 / 3991.3 / 4034.6 \$），求解 11.8–14.8 s vs MIP 63.2–218.8 s。

> 注：[B] 与 [C] 是同一团队（Q. Wang / Wenchuan Wu 等）的姊妹工作，算例与场景编号相同（3776.8…4034.6 \$ 组），引用时宜成对引用。

## 5. 映射到本工作区模型

### 5.1 边际循环成本
微网里充电的边际成本是买入电价 \(p_t\)，放电的边际收益是少买电价 \(p_t\)（即 \(C^{DC}_t=-p_t\)），于是
$$\kappa^0_t=C^{CH}_t+\eta C^{DC}_t=p_t+0.81\times(-p_t)=0.19\,p_t$$
实测（脚本 `_txt/_check_prices.py`）：

| 数据 | 电价范围 | 负价 | \(\kappa^0=0.19p\) 范围 |
|---|---|---|---|
| 附件1（144 槽） | 0.3713 – 1.3952 | 无 | 0.0705 – 0.2651 |
| 附件4（52 560 槽） | 0.0076 – 1.7936 | 无（仅 9 槽 < 0.05） | 0.0014 – 0.3408 |

\(\kappa^0_t\ge0\) 对**全部时段**成立 ⇒ 由 [A] Theorem 1，**LP 松弛最优值精确，且最优解本身满足 \(z^\*_t=0\)（不含同时充放）**。
\(\kappa^0\) 只含价格与效率、**与场景无关**，故两阶段随机模型可**逐场景**直接套用。

### 5.2 τ 罚项的作用
加入 \(\tau(c+d)\) 后，按 [A] 的分解，\(z_t\) 的系数变为
$$\kappa^{0,\text{eff}}_t=0.19p_t+\tau(1+\eta)=0.19p_t+1.81\tau>0\ 	ext{（严格）}$$
即把 [A] 表 I 的**第 2 行（\(\kappa^0=0\)，退化）升级为第 1 行（\(\kappa^0>0\)，严格不含 SCD）**；在 [B]/[C] 的语言里，这正是"用目标函数中的损耗罚项保证精确松弛条件成立"，且本工作区 \(\tau=10^{-6}\ll p\)，与 [B] 判据、[C] 的"\(\sigma\) 足够大"精神一致。

### 5.3 保 SOC 配对消去的位置
\(c\leftarrow c-\delta^\*,\ d\leftarrow d-\eta_c\eta_d\delta^\*,\ \delta^\*=\min(c,\ d/(\eta_c\eta_d))\) 正是 [A] 中"令 \(z_t=0\)、按互补动作恢复"的那一步（Algorithm 1 第 6/9–10 步）。[A] 证明：在 \(\kappa^0_t=0\) 的时段做此恢复**不改变最优值**（仅去掉退化表示）——这解释了旧 LP 版那些"贴 SOC 下限、集中在 slot 0"的同时充放槽为何能被安全消去。
注意 [C] 的引言把"可行解恢复"类方法评为 *"can only ensure a suboptimal feasible solution with double computational burden"*（针对其文献 [12,13]）；本工作区的做法因伴随 \(\kappa^0\ge0\)，属于**不损最优值的恢复**（[A] Theorem 1 保证），比该评价更强。

### 5.4 逐槽核验
365×144 槽 \(\max\min(c_t,d_t)=0\)（`02_验证/p2_arithmetic.json` 的 `"simultaneous": 0.0`）＝ 文献所说的数值核验（[B] 表 3、[C] 表 II 用"relaxed 与 MIP 目标值完全相同"作验收）。

## 6. 可直接引用的表述（建议放进方法节）

> 储能充放电互补约束 \(0\le c_t\perp d_t\ge0\) 可精确松弛：文献 [A] 证明，当边际循环成本 \(\kappa^0_t=C^{CH}_t+\eta C^{DC}_t\ge0\)（或该时段循环空间 \(\bar z_t=0\)）时，松弛问题的最优值与原 MILP 相同，且最优解不含同时充放电。本文算例中 \(\kappa^0_t=p_t+0.81(-p_t)=0.19p_t\ge0.0014>0\) 对全部时段与全部场景成立（附件1、附件4 电价均为正），故 LP 松弛精确；为进一步消除 \(\kappa^0_t=0\) 时段的退化表示，本文在目标中引入吞吐罚项 \(\tau(c_t+d_t)\)（[B] 证明此类损耗罚项可使精确松弛条件成立，[C] 给出相应充分条件），并采用保 SOC 的配对消去恢复互补解（[A] Algorithm 1；该恢复不改变最优值）。全年 365×144 槽核验 \(\max\min(c_t,d_t)=0\) kWh。

## 7. 仍需补的论证（答辩风险点）

1. **不要直接搬 [B] 的罚参数判据 (30)**：它是针对**损耗型罚项** \(\sigma[p^{dc}(1/\eta^{dc}-1)+p^{ch}(1-\eta^{ch})]\) 推出的，与本工作区的 \(\tau(c+d)\) 形式不同。要么在论文里说明"τ 仅作平局打破、精确性由 [A] 的 \(\kappa^0\ge0\) 保证"（**推荐**），要么把罚项改成 [B] 形式并补 \(\sigma\) 的标定。
2. **[B]/[C] 的阈值表达式依赖"套利项写在目标里"**：本工作区的购电成本藏在供能约束中（禁售电 + 可弃光使平衡成为单边不等式），若要在论文中给出 LMP 型阈值，需按 [B] Appendix A 的 KKT 推导**重推一遍**，不宜直接引用其数值。
3. **随机性**：[A][B][C] 均为确定性模型；本工作区为两阶段随机 LP，需写明"逐场景套用（\(\kappa^0\) 与场景无关，只含价格与效率）"。
4. **保留数值兜底**：条件均为充分（[B][C]）或充要但需查最优轨迹（[A]），仍应保留逐槽 \(\min(c_t,d_t)=0\) 核验；若要做"松弛 = MILP"的强验收，可补一次 LP vs MILP 目标值对照（[B] 表 3、[C] 表 II 的做法）。
